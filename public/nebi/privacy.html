Nebiデータの取り扱い

Nebi / Privacy

プライバシーポリシー

更新日: 2026年9月27日

Nebiは、KOKOA（以下「運営者」）本人が自分の予定・生活情報を管理する個人用アプリです。一般の利用者を募集するサービスではありません。

アクセスするGoogleデータ

本人のOAuth同意に基づき、Googleカレンダーの一覧と、設定したカレンダーの予定を読み取ります。予定の識別子、タイトル、開始・終了日時、終日・仮予定・キャンセルの状態、場所、自分の出欠状態を取得・処理します。予定の作成・変更・削除の権限は要求しません。

利用目的

予定の定期取得、保存、検索、本人からの質問への回答、取得日時や取得失敗の表示に使用します。広告配信、データ販売、信用評価には使用しません。Google APIから取得した情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

外部サービスへの送信

定期取得はGoogle APIとローカルのプログラムで行い、LLMを呼び出しません。本人が予定について質問したときは、質問・関連する会話と、回答に必要な予定情報（タイトル、日時、場所など）をAnthropicのClaudeに渡し、回答を構成します。OAuthのトークンやクライアント秘密情報をLLMへ渡しません。

Discordで質問した場合は、その会話先へ回答を送ります。回答に含まれる予定情報はDiscordでも処理・保存され、会話先を閲覧できる人から見える場合があります。自動の予定通知は現在有効にしていません。外部サービスの処理・保存には各サービスのポリシーが適用されます。Googleデータを一般用途のAIモデルの学習用として提供しません。

保存と保護

取得した予定、取得日時、会話、問い合わせ結果は、本人が管理するWindows環境のファイルやデータベースに保存します。OAuth更新トークンはWindowsのユーザー単位の暗号化機能で保護します。予定や会話の保存ファイル自体にはアプリ独自の暗号化は施しておらず、端末・OSのアクセス制御で管理します。運営者が作成するバックアップに保存データが含まれる場合があります。

接続解除・削除・保存期間

Googleアカウントの接続済みアプリの管理からNebiのアクセスを取り消せます。取り消し後の新たな取得は停止しますが、保存済みの予定や会話は自動では削除されません。

保存データの自動削除期限は現在設けていません。削除する場合は、本人がアプリを停止し、認証ファイル、予定のキャッシュ、データベース内の関連する会話・問い合わせ結果、必要に応じてバックアップを削除します。外部サービスへ送信済みの情報は、各サービスの削除機能・保存方針に従って扱います。
